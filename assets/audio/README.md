# audio/ —— 音乐与音效

## 子目录

| 目录 | 内容 | 数量 | 格式 |
|---|---|---|---|
| `bgm/` | 主题曲、日常经营、战斗、节庆 | 4 | OGG，循环 |
| `ambient/` | 风声、流水、驼铃、巴扎喧闹、羊群、夜间虫鸣 | 8 | OGG，循环 |
| `sfx/` | 点击、建造、收成、挖掘、受击、翻页 | 15 | WAV 或 OGG，< 1 秒 |

## 规格

| 项 | 要求 |
|---|---|
| BGM 时长 | 60–90 秒，**必须能无缝循环**（首尾相接无爆音） |
| 环境音 | 10–30 秒循环 |
| 音效 | < 1 秒，峰值归一化到 -3 dB |
| 采样率 | 44.1 kHz |
| 声道 | BGM 可立体声；音效建议单声道（省空间且定位自然） |

## ⚠️ 这是赛事合规红线，请认真读

**木卡姆是活态的非物质文化遗产，不是公共素材。**

直接从网上找木卡姆录音放进游戏，有三重问题：
1. **法律风险**：多数录音有明确版权，赛事提交后被质询会很被动
2. **文化问题**：木卡姆的传承有具体的人和社群，直接取用不妥
3. **作品风险**：音乐类素材是赛事审核的重点核查项之一

### 三条可行路线（按推荐度）

| 路线 | 做法 | 评价 |
|---|---|---|
| **① 原创** | 找音乐专业学生，按木卡姆的调式特征创作**新曲**（不是改编现有曲目） | **最推荐**。合规，且可作为「文化创新」写进作品说明，反而成了加分点 |
| **② 明确授权的素材** | 只用标注可商用的音源库 | 注意：许多标"免费"的库禁止商用或要求署名 |
| **③ 氛围化处理** | 不用木卡姆，改用中亚风格的通用器乐；木卡姆的呈现交给角色对话与文字 | 保底方案，牺牲一点氛围但零风险 |

**我的建议是①。** 你已经有 7 个角色和完整的文化叙事，配一套原创的、带木卡姆调式特征的曲子，整件作品会完整很多。而且找音乐专业的同学合作，成本远低于你想象。

### 必须做的事

建立 [asset-licenses.md](D:\坎儿井\docs\asset-licenses.md) 并逐条登记：
每个音频文件的**来源、授权类型、授权证明文件或链接、录入日期**。
赛事若被质询，这份记录就是你的证据。

**原创曲也要登记**：记下创作者姓名、创作日期、授权范围（是否允许你商用/参赛/修改）。
口头授权不算，要有个书面记录（微信文字截图也行，但要留存）。

## 免费音效来源（仅限环境音与音效，不含木卡姆）

| 来源 | 注意 |
|---|---|
| Freesound（筛 CC0） | 逐个核对许可；CC-BY 需在作品里署名 |
| Pixabay Audio | 核对是否允许商用 |
| 自录 | 风声、水声、脚步声可以自己录，零风险且独一无二 |

环境音和交互音效**用现成的完全没问题**，这一块不存在文化敏感问题。红线只在**音乐**上。
