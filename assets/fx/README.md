# fx/ —— 特效

## 子目录

| 目录 | 内容 | 规格 | P0 |
|---|---|---|---|
| `water/` | 明渠水流、涝坝波纹 | 16×16，6 帧循环 | 是 |
| `dust/` | 挖掘扬尘、沙尘 | 32×32，6 帧 | 是 |
| `combat/` | 刀光、箭矢、命中、沙暴全屏 | 混合 | 否（S6 才用） |
| `../` | 建造完成、篝火、节庆光效 | 混合 | 否 |

## 命名

```
water/fx_flow_loop_06f.png          loop 表示循环播放
dust/fx_dig_burst_06f.png           单次播放不标 loop
combat/fx_hit_slash_04f.png
combat/fx_sandstorm_fullscreen_08f.png
fx_build_complete_08f.png
```

## 规格约定

| 项 | 约定 |
|---|---|
| 命名后缀 | `_loop` 循环 / 无后缀为单次 |
| 帧数标注 | `_06f` = 6 帧 |
| 帧率 | 演出 10 fps（像素风低帧率更有味） |
| 尺寸 | 与作用范围匹配，不要用大图缩小 |

## 优先级说明

P0 只有两组：**水流** 与 **挖掘扬尘**。

- **水流**（P0）：水是本作的核心资源，明渠和涝坝的水面必须有生命感。静态水面会让人觉得很"死"。
- **挖掘扬尘**（P0）：治水是主线玩法，玩家会反复看到挖掘动作。这个反馈不能省。

战斗特效可以等到 S6。**现在不要做。**

## 粒子 vs 逐帧

篝火、炊烟这类**不要出图**，用 Godot 的 `GPUParticles2D` 参数调就行。
出逐帧图既费工又不如粒子灵活。

沙暴全屏这种需要精确控制视觉的才出逐帧图。
