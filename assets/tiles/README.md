# tiles/ —— 地图块

地图由这些格子拼出来。**这是整个游戏里数量最多的一类素材，也是最先要出的。**

## 子目录

| 目录 | 内容 | P0 数量 | 规格 |
|---|---|---|---|
| `terrain/` | 沙漠地表、戈壁碎石、绿洲草地（贫/中/茂）、道路、雪山山麓、悬崖岩壁 | 38 | 16×16（雪山与悬崖 32×32） |
| `farmland/` | 田地底、四种作物各三阶段生长 | 12 | 16×16 |
| `water/` | 明渠（直/弯/交叉/端头）、涝坝水面、暗渠口 | 7 | 16×16 + 6 帧循环动画 |
| `props/` | 胡杨、白杨、果树、灌木、杂草、石块、骨骸、陶片 | 14 | 16×16 / 32×48 |

## 命名

```
terrain/desert_light_01.png            变体用两位序号
terrain/grass_lush_03.png
water/canal_straight_anim_06f.png      动画标帧数 + f
water/reservoir_level_02.png           涝坝按水位分级
farmland/wheat_stage_02.png            作物按生长阶段
props/poplar_tree_spring.png           树按时令（如需季节变化）
```

## 出图顺序建议

1. **沙漠 + 绿洲草地（贫/中/茂）** —— 这三样先出。
   绿洲从荒漠中"生长"出来是本作最重要的视觉表达（GDD 8.1），
   三种草地浓度能直接表现这种变化。先出这三样，你就能看出游戏好不好看了。
2. 道路 + 水（明渠、涝坝）
3. 农田三阶段
4. 剩下的地形与道具

## 注意

- **地形块必须无缝拼接**（seamless tileable）。生成时在 prompt 里加这个词。
- 悬崖/岩壁需要**自动拼接**（Godot 的 Terrain 或 TileMap 自动图块），
  出图时按 47 或 16 个位掩码变体出，或先用简化版。
- 光照统一来自**左上**（见 [ART_STYLE.md](D:\坎儿井\assets\ART_STYLE.md) 第一节），否则拼在一起会出现方向矛盾的光影，非常明显。
