## 三条硬规则

1. **先定分辨率再出图。** 640×360 还是 960×540（见 ART_STYLE.md 第五节），这个决定影响所有图的尺寸，定了就不能改。
2. **AI 生成的图必须过一遍统一后处理**（降色到 32 色板 + 最近邻缩放 + 清理半透明边缘）。不做这步，第 20 张图之后风格必然散架。
3. **每引入一个素材都要登记授权**，含 AI 生成图（记工具、日期、prompt）。见下方。
