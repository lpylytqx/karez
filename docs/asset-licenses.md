---

## 登记规则

每引入一个素材（图片、音频、字体、参考图），立刻在下方对应的表里加一行。

| 字段 | 填什么 |
|---|---|
| 文件路径 | 相对 `D:\坎儿井\` 的路径，如 `assets/tiles/terrain/desert_light_01.png` |
| 来源 | 平台名 + 具体 URL。素材包写购买页面，AI 生成写工具名 |
| 授权类型 | CC0 / CC-BY / CC-BY-SA / 商业授权 / 原创 / AI 生成 |
| 授权证明 | 授权文件路径、订单截图路径，或"平台页面已注明可商用" |
| 录入日期 | YYYY-MM-DD |

**CC-BY 与 CC-BY-SA 要求署名** —— 这类素材必须在游戏的**致谢页**列出署名。
如果不想在游戏里加致谢页，就只选 CC0 或已购买商业授权的素材。

### ⚠️ 原创音乐也要登记

如果是找音乐专业的学生创作，仍然要登记，因为**口头授权不算证据**：

| 字段 | 填什么 |
|---|---|
| 创作者 | 姓名（网名不够，要真实姓名或可追溯的账号） |
| 授权范围 | 明确写出：允许本项目商用 / 参赛 / 修改 / 二次分发 |
| 证明 | 书面记录。微信/QQ 聊天截图也算，但要留存文件，比如 `docs/licenses/bgm_authorization.png` |
| 日期 | 授权达成日期 |

**建议直接写一份简单的授权书**（一页纸，签字或聊天确认），写清上述四项。
这件事花十分钟，能避免日后所有麻烦。
