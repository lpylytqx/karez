# 第一部分 · 新疆与坎儿井

**（第 1 屏：缩到最小的荒漠全景，绿洲只是沙海里的一小块）**

先说题材。

屏幕上这片地方，在新疆吐鲁番、哈密一带。

那里年降水量**不到 20 毫米**，蒸发量却是它的上百倍。

按理说，这种地方长不出东西。

**但它长出了葡萄、哈密瓜和棉花。**

靠的就是坎儿井 —— 一种由**竖井、暗渠、明渠、涝坝**四部分组成的
地下引水工程：把天山雪水在地下暗渠里送几十公里，避开蒸发，再引到地表。

这项工程，在吐鲁番、哈密一带**用了两千多年**。

「**坎儿井开凿技艺**」已经列入**国家级非物质文化遗产名录**；
「**新疆坎儿井**」在 2014 年入选**世界灌溉工程遗产名录**。

而它更重要的是一种生存智慧 ——

不与沙漠对抗，而是顺着地下水位走；

不追求宏大，而是几百口竖井、几十公里暗渠，**一代人挖一段，一直挖到今天。**

# 第二部分 · 这是什么游戏

**（第 2 屏：中景，一座完整的绿洲驿站聚落）**

我们说，这样一个题材，最合适的载体是**游戏**。

因为坎儿井本身就是一道**资源瓶颈** —— 在干旱区，它是唯一稳定的水源。

**瓶颈意味着取舍，取舍就意味着玩法。**

这就是《坎儿井》，一款 2D 经营游戏。

玩家扮演丝路上一位年轻的**驿丞**，接手沙漠边一座荒废的驿站，
从挖通第一段竖井开始，把荒漠重新经营成一座丝路重镇。

画面里现在看到的，就是它成熟之后的样子。

下面我们回到最开始，从头看一遍。

# 附录 A · 如果老师问「这怎么玩」

**基本操作**

| 操作 | 作用 |
|---|---|
| `WASD` / 方向键 | 移动主角 |
| 点地图上的空位 | 派一名居民过去 |
| 「推进时段」 | 晨 → 午 → 暮 → 夜，每过完一天结算 |
| 滚轮 / `+` `-` | 缩放地图 |
| 按住左键拖动 | 平移地图 |
| `F` | 镜头回到主角 |
| 底部输入框 | 与角色对话 |

**一天是怎么过的**

- 一年 **120 天**，四季各 **30 天**；每天 **4 个时段**。
- **每个时段 2 个行动点** —— 挖井、建造、派人都要花行动点，所以「做什么」本身就是取舍。
- 每天结算产出与消耗，然后掷骰决定有没有事件或灾难。

**新手最容易卡住的三件事**

1. **先挖井，别的往后放。** 出水量决定人口上限，人口决定你手上有几个人。
2. **留 1–2 人「待命」。** 全派出去看着效率高，出事时没人可用。
3. **秋天就开始囤。** 冬天牲畜会掉、食物消耗更快，葡萄干和毡子要提前备。

# 附录 B · 如果老师问「怎么样算通关」

游戏**不设统一终点**：无期限模式下，玩家自己定目标。

**四条胜利路线**（达成任意一条即为胜利）

| 胜利 | 条件 |
|---|---|
| 水源大成 | 坎儿井 6 段全通 + 明渠 4 条 + 涝坝 4 级 |
| 商路枢纽 | 4 条商路全通 + 巴扎建成 + 繁荣度 ≥ 480 |
| 文化鼎盛 | 举办木卡姆集会 + 声望 ≥ 88 + 奏乐台建成 |
| **绿洲名城**（终极） | 繁荣度 ≥ 700 + 声望 ≥ 95 + 人口 ≥ 95 |

**六档称号**：荒驿 → 小驿 → 通驿 → 重镇 → 丝路名驿 → **绿洲名城**

**四条失败条件**（**不会立刻结束**）：水源断绝、居民离散、据点被破、声望崩塌。
游戏会给 **3 天「最后一搏」窗口**，并告知补救条件 —— 为了不让人挫败。
