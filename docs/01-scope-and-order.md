# 单人无期限项目的建设顺序

> 前提：1 人，无截止日期，Godot 4.4，目标是一个**能完整演示核心循环**的可玩版本。

---

## 一、先说结论：你的敌人不是时间，是"半成品堆积"

无期限 + 单人，最常见的失败不是做不完，而是**同时在推进 6 个都完成 70% 的系统**，结果没有一个能演示。
GDD 里的 M1→M6 是按"系统模块"切的，那适合团队并行。单人必须**按"纵向切片"切**：

> ❌ 横向：先做完所有数值 → 再做所有 UI → 再做所有 AI → 最后拼起来（拼起来时发现处处对不上）
> ✅ 纵向：先让"一个坎儿井 + 一个角色 + 一次对话"完整可玩，再横向加宽

---

## 二、建设顺序（每阶段结束都必须「可运行、可演示」）

| 阶段 | 交付物 | 可演示的样子 | 完成标志 |
|---|---|---|---|
| **S0 现在** | 设计数据 + 架构 | 没有画面，但有完整数值表和事件库 | `numbers.json` / `events.core.json` / `characters.json` 齐备 |
| **S1 M1 闭环** | AI 管道 | 黑色命令行/极简界面，打字机吐出一段 AI 叙事，水粮数字随之变化 | 拔网线不崩，降级 demo 模式 |
| **S2 治水核心** | 坎儿井挖掘 + 水循环 | 能点竖井挖掘、看到水源增长、绿洲颜色变绿 | 能靠治水从"将死"走到"存活" |
| **S3 经营骨架** | 建造 + 人口 + 日程 | 能建驿馆/仓库，能安排居民干活，能过完一个季节 | 资源循环自洽，能自给自足 |
| **S4 AI 角色** | 3 个角色（老坎匠/木卡姆艺人/商队掌柜） | 能对话、有记忆、会记住上次的承诺 | 关掉 AI 后这三人明显"死掉" |
| **S5 事件与探索** | 地图 + 事件触发 | 派队出门、遇事件、带回资源 | 事件从 `events.core.json` 驱动，非硬编码 |
| **S6 战斗** | 回合制战斗 | 马匪来袭，AI 指挥敌人针对你的布防 | 一场完整的攻防打完 |
| **S7 博弈与外交** | 谈判系统 | 与商队讨价还价，AI 会虚张声势 | 信息不对称真实存在 |
| **S8 打磨** | 美术音效 + 路演 | 3 分钟能演完全部卖点 | 演示脚本可一次过 |

**单人现实预估**：S1 约 1–2 周，S2–S3 各 2–4 周，S4 约 3–5 周（AI 调试最耗时），S5–S7 各 2–4 周，S8 视美术方案而定。总计通常在 4–8 个月量级——**不用赶，但要防止 S4 无限拖延**。

## 三、必须守住的四条纪律

### 1. 数值与 AI 的边界，从第一行代码就要划清
`numbers.json` 是唯一数值真源。AI 只能提出"意图"（如 `{"intent":"trade","item":"silk","qty":5}`），
价格由本地代码按物价表算。**一旦让模型输出数字并写进状态，后期必然出现"钱莫名其妙变多"的调试地狱。**

### 2. 每个 AI 输出都要有 schema 版本号和兜底
模型升级、prompt 微调、网络抖动都会让输出格式偏移。校验失败时**用预设内容顶上**，绝不让游戏崩在演示现场。

### 3. 单机也要"存档即可复现"
JSON 存档 + 随机数种子。否则你调出一个复杂 bug 后无法重现，只能靠记忆猜——单人项目里这是最大的时间黑洞。

### 4. 美术最后定型，但规格现在就定
美术资源需求表（`docs/04-art-checklist.md`）**现在就要按最终分辨率写死**。
否则等 S8 才发现地图块尺寸不对，全部返工。

---

## 四、无期限下的"防烂尾"机制

既然没有截止日期，用**可演示性**代替 deadline 作为约束：

1. **每个阶段结束必须录一段 30 秒视频存档**（哪怕画面很丑）。累积下来就是开发日志，也是赛事材料的素材。
2. **永远保持主干可运行。** 新功能开分支或加开关，不要在主线上留半成品。
3. **每完成一个阶段，回头问一次："现在关掉 AI，游戏还成立吗？"** —— 这是 GDD 的核心判定标准，也是防止自己后期偷懒把 AI 做成贴图的自检。
4. **不要提前做 M5/M6。** 博弈和外交依赖角色记忆系统成熟，早做必然重写。

## 六、下一步（此刻该做的）

1. 读 `docs/02-numbers.md` 和 `data/numbers.json`，**确认数值手感**（尤其是"水"的紧张度是否符合你想要的体验）
2. 读 `data/characters.json`，**改角色人设**——这是你作为创作者最该亲自把关的部分，AI 只是执笔
3. 按 `docs/04-art-checklist.md` 决定美术方案（AI 生成 / 买素材 / 手绘）
4. 装 Godot 4.4，打开 `scripts/project.godot` 确认能跑
5. 办 DeepSeek 账号，按 `ai_backend/.env.example` 填好 Key（**不要提交进 git**）
6. 然后进 S1：跑通 M1 闭环
