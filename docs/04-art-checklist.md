# 美术资源需求表

> **规格现在就锁定，不要等到 S8 再定。** 单人或小团队最常见的返工来源就是"做到一半发现尺寸不对"。
> 本表按 **Godot 4.4 像素风** 写定。若最终选暖色手绘风，数字可乘以 2（见 §6 换算表）。

## 一、分辨率与尺寸规范（不可变）

| 项 | 规格 | 理由 |
|---|---|---|
| 逻辑分辨率 | **640 × 360** | 16:9，1 单位 = 1 像素，便于像素对齐 |
| 视口缩放 | 整数倍，默认 **3×**（输出 1920×1080） | 像素风禁止非整数缩放，否则糊 |
| 地图格 | **16 × 16 px** | 经营与战斗共用同一套格子 |
| 角色精灵 | **16 × 24 px**（站立）/ 16 × 16 px（俯视走路） | 24 高便于表现体型差异 |
| 建筑精灵 | 小 32×32 / 中 48×48 / 大 64×64 | 大建筑跨格，锚点在底部中心 |
| 立绘 | **512 × 512 px** 源图，显示时缩到 384×384 | 留余量，支持高 DPI |
| UI 九宫格 | 24 × 24 px 切角 | 可拉伸不糊 |
| 图标 | 16×16（小）/ 32×32（中） | — |
| 帧率 | 步行 6 fps / 动作 8 fps / 演出 10 fps | 像素风低帧率更有味 |

**色彩规范：**

| 用途 | 色值 | 说明 |
|---|---|---|
| 沙漠主色 | `#D9B382` | 暖金黄，基调 |
| 绿洲青绿 | `#5A8F6B` | 生长感，与沙漠强对比 |
| 雪山白 | `#E8EEF2` | 冷色，用于水与远景 |
| 火焰山赭红 | `#A8522F` | 强调色，用于危险与战斗 |
| 生土建筑 | `#C9A277` | 建筑主体 |
| 木/葡萄架 | `#8B6B47` | 结构 |
| UI 底色 | `#2B2118`（半透明 85%） | 深褐，避免纯黑 |
| UI 文字 | `#F0E4D0` | 米白，保证可读 |
| 强调/选中 | `#E0A43C` | 金 |

> 色板控制在 **32 色以内**，这是风格统一的第一道保障。把上表交给任何画师或 AI 生成器作为约束，可大幅减少风格漂移。

### ⚠️ 音频授权是赛事合规红线

**木卡姆是活态的非物质文化遗产，不是公共素材。** 直接使用网上找到的木卡姆录音有极高的侵权风险，且文化上也不妥（涉及传承人权益）。

三条可行路线，按推荐度排序：

1. **原创**：找音乐专业学生按木卡姆的调式特征创作新曲。既合规，又可作为"文化创新"的加分点写进作品说明。**最推荐。**
2. **明确授权的免费/CC0 音源**：只用明确标注可商用的素材库（注意：许多"免费"库禁止商用或要求署名）。
3. **氛围化处理**：不直接使用木卡姆，改用中亚风格的通用器乐，把木卡姆的呈现交给角色对话与文字。

**你必须做的事**：建立一份 `docs/audio-licenses.md`，逐条记录每个音频的来源、授权类型、授权文件或链接。赛事若被质询，这份记录就是你的证据。

## 四、字体（P0，且最容易踩坑）

| 用途 | 要求 | 推荐 |
|---|---|---|
| 中文正文 | 可商用、含常用汉字、清晰 | 思源黑体 / 思源宋体（SIL OFL，可商用） |
| 数字与英文 | 像素风或几何无衬线 | 搭配像素字体时注意中英混排基线 |
| 标题 | 有地域感但不做作 | 建议从思源宋体加粗改造，不要用装饰性过强的"民族风"字体 |

**三个坑：**
1. **不要用系统默认字体交付**。对方电脑可能没有。
2. **字体必须内嵌进 Godot 项目**，并在授权文件里记录许可。
3. **像素风慎用中文点阵字体**：汉字笔画多，640×360 分辨率下 12px 汉字会糊。建议 UI 中文用矢量字体在更高层渲染，或把逻辑分辨率提到 960×540。

> 建议：若你打算大量用中文 UI，**把逻辑分辨率从 640×360 提到 960×540**（仍为 16:9，缩放改 2×）。这样汉字可读性大幅提升，代价是像素风"粗颗粒"感略降。这是一个需要你现在就决定的取舍。

## 五、三种美术方案对比

| 方案 | 成本 | 风格统一性 | 工作速度 | 法律风险 | 适合 |
|---|---|---|---|---|---|
| **A. AI 生成 + 人工修** | 低（时间成本） | **差**（最大问题） | 快 | 中（需注意训练数据争议与平台条款） | 一人开发、无预算 |
| **B. 购买素材包** | 中（数百元） | **好** | 最快 | 低（有明确授权） | 想省时间、接受风格妥协 |
| **C. 手绘 / 委托画师** | 高 | **最好** | 慢 | 无 | 有预算、追求品质 |

### 我推荐的组合（针对你 1 人、无期限的情况）

**方案 A + 固定色板 + 统一后处理**：

1. **先定色板**（用 §1 的 32 色），把它作为所有生成图的强制约束。
2. **固定描述模板**，例如：`2D pixel art, top-down view, 16x16 tile, warm desert palette limited to 32 colors, no outlines, soft shading, 生土建筑 style`。生成时只改主体词，不改风格词。
3. **统一后处理脚本**：所有生成图批量做"降色到同一色板 + 最近邻缩放 + 去抗锯齿"。这一步能把 AI 生成图的风格漂移压下去一大半。
4. **立绘单独处理**：立绘可以精致，不必强求像素风。512×512 手绘感立绘 + 像素风地图是常见且好看的组合（如《八方旅人》的思路）。

**这一套的关键是第 3 步。** 没有统一后处理，AI 生成的美术在第 20 张之后一定会散架。

## 六、若改选暖色手绘风的换算

| 项 | 像素风 | 暖色手绘风 |
|---|---|---|
| 逻辑分辨率 | 640×360 | 1920×1080（或 1280×720） |
| 地图格 | 16×16 | 32×32 或 64×64 |
| 角色精灵 | 16×24 | 64×96 |
| 立绘 | 512×512 | 1024×1024 |
| 动画 | 4 帧 | 8–12 帧（更费力） |
| 数量影响 | 基准 | **工作量 × 2.5–3** |

**建议**：以你的人力，**像素风是明显更优的选择**。手绘风对动画帧数的要求会让 S8 无限延长。
