# 怎么玩《坎儿井》

> 这一页回答一件事：**打开游戏之后我到底该点什么。**
> 如果你也有"看着它不知道干嘛"的感觉，那多半是因为早期版本确实没有中局 ——
> 材料没有来源，挖完第一段竖井就卡死。S3 经营骨架补上之后才成立。

---

## 一、一句话目标

**在饿死之前，把坎儿井挖通。**

沙漠边上有一座绿洲，水快干了。坎儿井是唯一的水源 —— 挖得越深，水越多，能种的田越多，人就活得下去。

```
挖竖井 → 水变多 → 田变多 → 粮变多 → 人能养活 → 有人来投奔 → 劳动力更多 → 能挖更深的井
   ↑                                                                              │
   └──────────────────────── 采木取土（材料从这来）──────────────────────────────┘
```

---

## 二、开局：照这个顺序点（约 10 分钟）

### 第 1 步　先挖第一段竖井

点右侧 **「挖竖井」**。

- 会扣掉 木12 土25，工期 2 天
- 顶栏「建设:」会变成「第一段竖井（井口段）」
- **但工期不会自己走** —— 需要有人治水（开局已经派了 3 人）

### 第 2 步　确认分工

点右侧 **「分工 ▾」**，看这个面板：

```
── 分工（每个人占一个岗位）──
治水　　3 人      −  ＋
采木　　1 人      −  ＋
取土　　1 人      −  ＋
做工　　0 人      −  ＋
耕作　　1 人      −  ＋
守卫　　0 人      −  ＋
待命　　0 人      −  ＋
全部 6 人已分配
```

**这是整个游戏最重要的界面。** 6 个居民，每人每天占一个岗位：

| 岗位 | 作用 | 什么时候要人 |
|---|---|---|
| **治水** | 推进坎儿井工程。**没人治水，工期完全不动** | 只要在施工，至少 2–3 人 |
| **采木** | 每人每天 木 +8 | 要挖井就得有 |
| **取土** | 每人每天 土 +12 | 要挖井就得有 |
| **做工** | 每人每天 工具 +1 | 工具不够时（第 5、6 段各要 4、6 把） |
| **耕作** | **1 人管 4 块田** | 粮不够时 —— 这是最关键的岗位 |
| **守卫** | 治安 +5/人 | 来了马匪消息之后 |
| **待命** | 士气 +0.5/人/天 | 士气低的时候 |

### 第 3 步　推进时间

点 **「推进时段」**。每点一次走一个时段：**晨 → 午 → 暮 → 夜**。

**点满 4 次 = 过一天。** 过一天才会：
- 水入账、粮扣除
- 岗位产出结算（采的木、土的土、种的粮）
- 施工推进
- 可能有人来投奔 / 有人离开

### 第 4 步　每天看右栏底部这一行

```
田 6 块 井 1/6
昨产 木8 土12 粮9
```

**「昨产」就是你调整分工的依据。** 比如看到 `粮 9` 而 6 个人每天要吃 18 —— 那就得把更多人派去耕作。

---

## 三、什么时候该改分工

游戏有一套自己的压力，照着应对就行：

| 看到什么 | 说明 | 怎么办 |
|---|---|---|
| 顶栏出现 **「← 缺水，入不敷出」** | 日出水 < 人口消耗 | 挖竖井。这是唯一的解法 |
| 右栏 **「昨产 粮」低于「人口 × 3」** | 在吃老本 | 加耕作的人；同时继续挖井（田块数跟井的段数走） |
| **粮 数字变成 0** | 已经开始饿死人了 | 立即把所有能撤的人派去耕作 + 采木取土换粮 |
| **「缺 土差N」** | 挖不动了 | 派人取土 |
| **「缺 工具差N」** | 同上 | 派人做工 |
| **「施工中…」但天数不减** | **没人治水** | 派人治水 —— 这是最容易踩的坑 |

## 四、关键数字（记这几个就够）

| 项目 | 数值 | 含义 |
|---|---|---|
| 开局水 | 90 方，日入 5 方 | 6 人每天要 18 方 → **净亏 13/天，只够 7 天** |
| 开局粮 | 78 | 6 人每天吃 18 → **只够 4.3 天** |
| 第一段竖井 | 木12 土25，2 天 | 开局材料刚好够 |
| 每段竖井 | +55 方水/天 | **挖通一段，水就彻底不是问题** |
| 田块数 | 井的段数 × 6（上限 24） | 6 段 = 24 块田 |
| 每块田 | 1.59 粮/天，1 人管 4 块 | 一名农夫 = 6.4 粮/天 |
| **自给自足的临界点** | **2 段竖井** | 12 块田 + 采集 ≈ 23 粮/天 > 18 |

**所以前 10 天的核心就是：尽快挖到第 2 段。**

## 五、推荐故事线

数值循环之外，这个游戏还有一层 —— **和角色说话**。底部输入框可以直接跟 7 个角色对话，走的是真实 DeepSeek。

### 推荐的开场三问

```
① 老坎匠，这井还有救吗
② 看看第三口竖井
③ 派叶尔兰出去探探路
```

### 一条能跑出味道的路线

1. **先问老坎匠**（他是老坎匠，嘴硬、认命、经验极老）
   - 问井、问土、问他那条腿是怎么伤的
2. **挖完第一段，回来告诉他**
   - 他会有反应 —— 因为他**记得**
3. **对他许一个诺**，比如：
   ```
   等这季葡萄卖了钱，我一定给你换一套新的坎土曼，说话算话。
   ```
4. **过几天再问他**
   ```
   老坎匠，我上次答应你的事，还记得吗？
   ```
   **他会复述出具体细节**（实测他会说"那把镢头。松头的那个。"）。这是这个游戏最像"活人"的地方。

### 其他角色各自管什么

| 角色 | 找他聊什么 |
|---|---|
| **老坎匠** | 坎儿井、土质、水脉。他是唯一懂行的人 |
| **木卡姆艺人** | 士气、节庆、巴扎人气 |
| **哈萨克骑手** | 探路、草原牧场、马匹 |
| **商队掌柜** | 物价、买卖、商队何时来 |
| **厨娘** | 粮食、加工、怎么把粮做成馕 |
| **神秘旅人** | 主线悬念（他为什么来、坎儿井为何淤塞） |
| **马匪头目** | 威胁、谈判。治安低的时候他会来 |

## 六、三种常见的死法

| 死法 | 怎么发生的 | 怎么避免 |
|---|---|---|
| **渴死** | 一直不挖井，7 天后水见底 | 开局第一件事就是挖竖井 |
| **饿死** | 不派耕作，粮 4 天就没了 | 右栏「昨产 粮」低于人口×3 就加耕作 |
| **懒死** | 井在施工但没人治水，工期永远不走 | 看「施工中」时确认治水人数 > 0 |

## 八、给开发者的注记

这一页的存在本身说明了一件事：**S2 只做了"挖井"，没做"材料从哪来"。**

数值算得明明白白 —— 初始材料 木30 土50 只够挖 1 段，而第 2 段要 土40。**玩家必然卡死。**

`01-scope-and-order.md` 里 S3「经营骨架」写的正是这件事。跳过它直接做 S4 是个错误，
现在补上了：`population.jobs.list` 那 9 个岗位、`resources.materials.gathering` 的采集产出、
`agriculture.farmland` 的田块增长 —— 这些**早就写在 numbers.json 里了**，只是从没被代码引用过。

补完之后用 60 天自动模拟验证过（`scripts/tests/logic_test.gd` 的 `_test_s3_loop`）：

```
第 1天  段0  水 77  粮 66  人6   ← 将死
第10天  段2  水300  粮  4  人6   ← 最低谷
第30天  段3  水300  粮 81  人5   ← 粮开始积累
第60天  段3  水300  粮234  人9   ← 存活并繁荣
```
